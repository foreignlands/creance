## 已修复（本轮提交）

### 正确性（9 项）
1. **stop 梯队空转**：SIGTERM 等待以 pidfile 存活判定，而 `pidfile::stop`
   先删文件 → 等待首轮即假成功，SIGKILL 段永不可达；`delete()` 可把仍
   在关机的 qemu 的实例目录整个删掉（覆盖盘被 unlink、进程失管）。等待
   改为直接探测**进程**（新 `pidfile::process_alive`）。
2. **wait_ssh 盲轮询**：qemu 启动即死（hostfwd 端口被占）会白等 10 分钟。
   现每轮询先查 pidfile，死即报"端口被占用或启动即败，看 serial.log"。
   （ssh_local_port 在 setup 时分配、冻结进 instance.json，属已知 TOCTOU
   窗口，早退检测把后果从 10 分钟挂起降到秒级报错。）
3. **up 失败残留半开机 VM** → 失败路径现在主动 stop。
4. **macOS 两处裸 `limactl`**（ssh_target/instance_running）未走
   FINDING-010 的 strip-then-set 环境纪律：用户 shell 导出 LIMA_HOME 时
   查询全局 home 而其它操作用 profile home。已统一。
5. **doctor 在 aarch64 误报 qemu 缺失**（硬编码 qemu-system-x86_64）→
   按 `runner::qemu_binary()` 取。
6. **pgrep 缺席时孤儿收割静默失灵** → pgrep 进 require_tools 与 doctor。
7. **workspace 含单引号会击穿 guest 挂载脚本** → setup 时拒绝；
   参数校验提到 ~600MB 镜像下载**之前**（坏参数不再先付下载代价）。
8. **镜像 SHA256 全量读入内存**（600MB Vec）→ 8MiB 分块流式。
9. **gate-daemon 缺守护纪律**（继承整壳环境、与 CLI 同进程组）→ 对齐
   relay 的 process_group(0) + strip_env。

## 待审查（需产品裁定，未动）

### A. 语义/设计决策
1. **escape 探针 3（proxy-numeric-endpoint）是空探针**：两个 match 臂都
   返回 Contained，永远不可能红。要么实现真校验（非数字主机=逃逸），要么
   删探针。——影响"已强制探针"的计数诚实性。
2. **relay 崩溃后 mihomo 成为无人认领孤儿**：stop 收不掉、端口被占，
   下次 start 报"端口已被占用"直到手杀。ssh 隧道有对应安全网
   （reap_orphans，F-026），核心没有。建议仿做。
3. **gate 看门狗 Closed 态每 500ms 两个 pgrep**（守护进程终身 2 次/秒
   fork）——建议改为状态变更后 N 个 tick 内收割。
4. **cage/creance 命名大扫除**（cage-relay、`Host: cage-proxy`、
   `User-Agent: cage`、SOCKS 用户名 `cage`）：**已裁定=应做**——封号
   防御研究（docs/BAN-DEFENSE-STUDY-2026-11-21.md）实锤常量品牌串是
   集群信号（上游 Cage #173/#605 同坑）；连 guest 的 `cage-` hostname
   前缀一并改为真实机型风格。排入 0.6.x。
5. **错误语言统一**：中英文混用无规律（同函数内都有）。定方向后一次扫。
6. **`fetch-proxy-core.sh` 无版本钉死、无完整性校验**——信任链最薄弱
   一环（对比：QEMU 后端对镜像做 SHA256SUMS 校验）。mihomo release 无
   per-asset 校验和资产，需定方案（钉版本+自录哈希入仓？）。
7. **ci.sh**：建议 `--locked`；Linux 跑时静默跳过全部 macos-gated 测试，
   "绿"的语义随平台漂移（可加提示行）。
8. `CLOUD-DEVIN.md`：80% 陈旧且零引用——退休或重写。
9. 低价值优化（默认不做）：proxy-start 就绪轮询每 100ms 三连 HTTP；
   copy_executable_if_changed 双份全读（~60MB×2）；`creance shell` 透传
   ssh 的 255 退出码（0/1/2 惯例外）。
