### Desktop 类——重大事实纠正：全都有 Linux 版

| 产品 | Linux 形态 | 接入路径 |

| Cursor | 官方 .deb/AppImage | guest 安装+Xvnc 应用通道 |

### antigravity cli 的诚实核查

Google Antigravity 本体是 IDE，官方独立 CLI 未见（社区有包装项目
confeden/Antigravity 1.7k）。**对用户的承诺口径修正**：首保目标=
Antigravity 在 guest 里可用（desktop 通道优先；若其内置 agent
有 headless/CLI 模式则同时暴露 cli 入口）。核实工作列入 0.8.6 任务。

## 二、产品方向深思考

### 2.1 我们到底卖什么——三个候选叙事的决断

| 叙事 | 问题 |
|---|---|
| "安全的代理/网络隔离工具" | 已否定——这是零件不是产品 |
| "多 agent 统一工作台" | vibe-kanban/opencode 们已占心智，我们无差异化 |
| **"敢让 agent 真干活的工作台"** | ✅ 唯一同时回答"能力全"和"敢用"的 |

第三个叙事的展开：用户装一堆 agent 之后的真实焦虑是——它们
要我的 API key、要读我的文件、要执行命令、要登录我的账号。
opencode/codex 再好用，用户也是在**裸机**上把命交给它们。
vibe-kanban 编排十个 agent，就是把攻击面乘十。
**creance 的卖点不是"能跑 agent"，是"agent 关进笼子后能力不打折"**
——竞品解决"多用"，我们解决"敢用"。这就是文案层面的产品定义：

> creance — 把所有 AI agent 关进同一个安全笼子里干活的工作台。
> 它们拿到完整 Linux 环境、真实浏览器、你的项目文件（你授权的
> 那些），但拿不到你的钥匙、你的主机、你的其他账号。

### 2.2 用户旅程重排（JTBD 视角）

用户的目标不是"配置代理"也不是"创建 VM"，是**"让我新买的 agent
开始干活，且我敢睡觉"**。旅程重排：

```
装包 → 向导3步(2分钟) → 左栏点亮 agent 图标 → 首次点它=自动安装
→ 终端/窗口打开 → OAuth 在内置浏览器完成 → 干活
→ 额度/账号在左栏管理 → 出门手机…（不做，砍掉）
```

关键设计：**agent 安装是懒惰的**——不预装一堆，用户点谁装谁，
安装进度在图标上直接显示（点第二次=打开）。这把 provision 的
可选组件层直接产品化。

### 2.3 差异化地基怎么变成用户可感知的卖点

安全地基用户看不见=不存在。翻译方案：

| 地基（我们已有） | 用户可感知形态 |
|---|---|
| fail-closed  egress | 盾牌+出口国别实时显示："你的流量从🇺🇸出去" |
| 证据链/探针 | "安全检查 11/11"绿钩列表，点开看证据 |
| 审批通道 | agent 做危险动作时手机/桌面弹"允许吗" |
| 钥匙串凭证 | "你的 API key 不在任何文件里"一句话+设置页佐证 |
| 指纹 persona | "这个环境的浏览器像一台普通 MacBook"（B类后期） |
| 多账号调度 | 左栏账号卡片+额度百分比 |

### 2.4 不做什么（再确认，防蔓延）

插件市场/手机端/云部署/多用户/团队版——全砍。单机单人多agent。

## 三、任务细化（0.8.3-0.8.9 重排，含验收标准）

### 0.8.3 节点接入重构（最痛点先行）
1. 三导入卡（订阅/粘贴或拖文件/手动）+节点卡片列表+点选应用
2. 主机网络下载订阅勾选（首次推荐）——fail-closed 语义不破：
   仅订阅文本，UI 明示
3. 本机 Verge/Clash/Mihomo 配置自动扫描+一键迁移
4. 订阅自动更新+错误给下一步动作
5. 验收：Mac 实机，从粘贴订阅到出口连通<2分钟；故意输错URL
   得到的错误带三个可点动作

### 0.8.4 三步向导
1. 向导框架（进度条/中断续走/过完即隐）
2. 第③步=探针可视化（复用证据链，逐项动画打勾）
3. 验收：空白机全程不碰终端到盾牌绿

### 0.8.5 工作台骨架+CLI agent 注册表（合并提速）

3. 首期内置：claude-code/codex/opencode/gemini-cli/aider/goose
   （全开源或 npm 可得）
4. 验收：点图标装 codex，终端里跑起来能干活

### 0.8.6 desktop agent 应用通道（Xvnc 泛化）
